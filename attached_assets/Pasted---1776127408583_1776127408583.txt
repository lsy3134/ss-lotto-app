📌 목표

특정 날짜의 배정 결과를 수정하거나 "다시 배정하기"를 실행하면
그 다음 날짜부터 자동으로 순번이 이어지도록 재계산 기능을 추가해주세요.

---

📌 현재 구조

- assignmentData: 날짜별 배정 결과 저장 (localStorage)
- savedSpare2: 날짜별 spare2 저장 (이미 존재)
- generateAssignment(): 배정 결과 생성 함수 (저장 X)

---

📌 추가 구현 요구

[1] 재계산 함수 추가

function recalculateFrom(startDate) {

  let currentDate = nextDate(startDate)

  let lastSpare2 = savedSpare2[startDate]?.[0]

  while (assignmentData[currentDate]) {

    const result = generateAssignment({
      firstNumber: lastSpare2
    })

    // 결과 덮어쓰기
    assignmentData[currentDate] = result

    // spare2 갱신
    savedSpare2[currentDate] = result.spare2

    lastSpare2 = result.spare2[0]

    currentDate = nextDate(currentDate)
  }

  // 저장
  localStorage.setItem('assignmentData', JSON.stringify(assignmentData))
  localStorage.setItem('savedSpare2', JSON.stringify(savedSpare2))
}

[2] 호출 위치 (중요)

아래 두 경우에 반드시 실행:

saveAssignment(date, result) {

  savedSpare2[date] = result.spare2

  recalculateFrom(date)

2. "다시 배정하기" 버튼 클릭 시

handleRegenerate(date) {
  const result = generateAssignment(...)

  saveAssignment(date, result)
}

}[6] 안전 조건 (중요)

recalculateFrom 실행 시:

- savedSpare2[startDate]가 없으면 실행하지 않음
